## Repository Organization and Configuration

Each project folder contains:

- An executed Jupyter notebook
- A project-specific README
- Saved results and visualizations
- Dataset access information
- Required libraries or a `requirements.txt` file
- Instructions for reproducing the work

## Running the Projects

1. Open the selected project folder.
2. Review its `README.md` for dataset and dependency information.
3. Open the `.ipynb` file in Google Colab or Jupyter Notebook.
4. Install the listed dependencies.
5. Run the notebook cells from top to bottom.
